# Maputo-Houses-Machine-Learning-Project-
A machine learning project that scrapes, cleans, and analyzes real estate data from Maputo, Mozambique, and builds predictive models for house prices.

Scraped real estate listings from a Maputo property website using Python and BeautifulSoup. Cleaned and explored the dataset, engineered relevant features, and developed a machine learning model to predict house prices based on property characteristics such as location, size, bedrooms, bathrooms, and parking.

## 📊 Project Overview

This project scrapes property listings from Property24 Mozambique, cleans the data, engineers features, and develops a machine learning model to predict house prices based on property characteristics such as:
- Location
- Number of bedrooms
- Number of bathrooms
- Parking spaces

## 🔧 Tools & Technologies

- **Python** - Core programming language
- **BeautifulSoup** - Web scraping property listings
- **Pandas** - Data cleaning and manipulation
- **Matplotlib** - Data visualization
- **Scikit-learn** - Machine learning model development
